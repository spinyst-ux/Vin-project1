# NCL HUB: Pixel Lineage

Executor script (Luau) that auto-plays Pixel Lineage: joins runs, attacks / uses skills by priority, perfect QTE (shots, dodge, barrage), auto path / event / chest, auto potion, auto sell, party invite, Discord webhook and game speed.

## Run
Execute `PixelLineage.lua` with your executor. Config auto-saves to `workspace/NCL HUB/PixelLineage/config.json`.

`macro.ps1` / `start.bat` / `ui.html` are the older screen-click macro (no injection).
